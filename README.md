🪄 Mythoria — The Art of Card Collecting

Enter a world of mystery, magic, and legendary cards.

 About the Project

Mythoria is a fantasy-inspired web application built around the experience of collecting cards, opening boosters, and creating personalized decks.

The project offers an immersive interface where users can explore magical cards, manage their collection through the Grimoire, and build their own Deck.

Developed as an individual project, Mythoria is an opportunity to practice front-end development, JavaScript logic, and DOM manipulation.

 Features

 Booster Shop: Explore available boosters and manage selections.

 Booster Opening: Discover cards through the booster-opening experience.

 My Grimoire: Display and manage collected cards dynamically.

 My Deck: Build a personalized deck using collected cards.

 Local Storage: Preserve supported application data between sessions.

 Fantasy UI: Enjoy a dark, magical visual identity.

 Responsive Design: Adapt the interface to different screen sizes.

 Technologies Used

HTML5 — Semantic page structure.

CSS3 — Layout, styling, animations, and responsive design.

JavaScript (ES6+) — Application logic, DOM manipulation, and interactive features.

LocalStorage — Client-side data persistence.

Git & GitHub — Version control and project management.
